# 技师无入住店铺访问与工作能力门禁

## 产品行为

- 从身份切换页进入技师端时，如果当前技师没有有效入住店铺，先显示“入住店铺”提示页。
- 提示页左上返回回到切换前页面；右上关闭进入技师端首页。
- 无店铺技师可以浏览技师端及个人日程，也可以记录私人行程。
- 出勤、移动中、服务中、休息等工作状态不可开启；正式后端同时拒绝无有效店铺从属关系的工作状态启动请求。
- 日程中的“可排班”和“手动预约”入口不显示，避免通过日程创建正式工作安排。
- 无店铺提示使用统一红色警示框体，并明确说明仍可浏览技师端以及恢复工作能力的条件。

## 数据与接口

- 未新增数据表、migration 或接口。
- `PATCH /api/v1/technician-work-status/me` 增加服务层门禁：启动在岗状态时必须存在当前有效店铺从属关系。
- 店铺资格继续来自正式 `TechnicianShopAffiliation` 数据，不新增前端缓存或模拟状态。

## 本地验证范围

- 入住店铺页的返回、关闭、红色提示与文案组件测试。
- 身份切换来源状态和技师入口提示门测试。
- 无店铺出勤按钮禁用及 API 不调用测试。
- 无店铺日程仍可查看私人行程、但不显示可排班/手动预约测试。
- 工作状态 Service/Repository 定向测试。
- 前端全量 Vitest、TypeScript 检查、i18n 检查与 production build。
