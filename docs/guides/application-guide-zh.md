# NeeDo 申请者操作教程

版本：2026-09-07。本文为待部署验收的中文教程草稿；页面按钮与流程以最终环境为准。

本文只介绍申请者操作，涵盖店铺申请、本人认证和技师入驻申请。截图中的姓名、店铺、地址、电话及银行资料均为 TEST 示例，不能作为填写依据。教程不包含登录凭据。

## 开始前：确认账号与申请入口

使用自己的 NeeDo 账号登录，在身份申请入口选择店铺或技师申请；本人认证从用户设置中的本人验证入口进入。

打开申请页面会读取已有申请。填写、保存草稿和最终提交是不同操作：只有确认提交，申请才进入审核。再次打开申请时，应先查看当前状态，再决定继续填写、撤回或重新申请。

如页面显示账号或权限错误，先确认当前账号是否为提交申请的账号。不要把另一账号的申请资料继续填入当前页面。

## 店铺申请：填写店铺与服务展示

1. 选择以个人或法人名义申请，填写页面要求的申请人、代表者及法人资料。片假名姓名应与本人资料或法人资料一致。

2. 填写店铺名称、营业地址、联系电话和负责人姓名。补充最近车站、所需分钟数及交通说明，让申请资料能够准确展示位置。

3. 选择服务分类与经营关键词，填写服务说明和价格范围。需要图片的字段，点击“上传图片”并选择对应文件。

4. 检查展示内容，点击底部“下一步”。返回上一步时，确认当前填写内容仍在；如果出现错误，按页面提示修正后再继续。

## 店铺申请：银行与身份资料

1. 从银行菜单中选择机构，核对自动显示的银行代码。目录外机构使用页面提供的自定义入口，准确填写名称与代码。

2. 填写支店名称、支店代码、账户号码和片假名账户名义。账户类型菜单为“普通預金”“当座預金”“貯蓄預金”“その他”，请选择开户资料中的实际类型。

3. 法人申请按页面要求提供法人登记资料。上传成功后仍需完成后续提交；上传本身不会代表审核通过。

4. 如果页面提示缺少本人认证，先进入本人验证，完成填写、确认和提交，再等待人工审核。是否必须先完成认证，以当前申请页面提示为准。

5. 如果重新进入时页面显示已保存的银行账户摘要，核对机构、支店和掩码信息。掩码用于识别已保存账户，不能作为账户号码重新填写。需要改用其他账户时，按页面提供的修改入口重新输入。

## 店铺申请：阅读合同并提交

1. 阅读当前页面显示的完整收费规则与 NeeDo 合同，核对版本及内容。合同读取失败时，点击“重试”，成功显示后再继续。

2. 确认已阅读并同意页面列出的条款后，勾选对应确认项。

3. 点击最终提交按钮。提交成功后，页面应显示已提交的资料和“审核中”；在出现成功状态前，不要把保存草稿当作已提交。

4. 再次打开店铺申请，可查看已提交的资料。审核中的资料用于审核，若需修改，先按页面提供的“撤回”操作处理。

## 本人认证：填写、确认与提交

1. 打开用户设置中的本人验证，填写姓、名及对应片假名。

2. 分别选择出生年、月、日及性别，填写邮政编码、都道府县／市区町村、街道门牌，并按实际情况填写楼栋或房间号。

3. 选择职业；选择“其他”时补充具体职业。本页不要求填写居住形态、联系方式、邮箱、银行卡或交易目的。

4. 点击“确认填写内容”，逐项核对确认页。需要修正时点击“上一步”；确认页尚不代表资料已提交或本人认证已通过。

5. 确认无误后点击“提交审核”。成功后显示“审核中”和已提交资料，等待人工审核；如有补充核验要求，请按平台提示配合。

6. 再次进入本人验证可查看当前申请。审核通过后，页面显示审核已通过；认证结果由正式审核决定，不能通过自行填写资料获得。

## 技师申请：选择店铺并提交资料

1. 进入技师申请，搜索希望入驻的店铺。核对店铺名称、位置和卡片信息，选择实际要绑定的店铺。

2. 在店铺卡片中完成单选。该选择决定申请提交给哪家店铺；提交前再次核对，避免向同名或位置不同的店铺申请。

3. 填写本人姓名、联系方式、城市、性别、生日、从业年数、服务区域、擅长项目和自我介绍等页面要求的资料。

4. 使用“上传图片”选择页面要求的本人照片或其他申请资料。按提示完成必填项，点击底部按钮继续检查并提交申请。

5. 提交成功后进入审核步骤，查看所选店铺和完整申请资料。审核由目标店铺处理，选择店铺或上传照片本身不会自动建立技师身份。

## 审核期间：撤回、重新申请与身份切换

审核中：页面显示禁用的“审核中”按钮。需要修改时点击“撤回”，成功后再编辑并重新提交；如果状态已被更新，重新进入页面查看最新结果。

审核未通过：阅读驳回原因，点击红色的“审核未通过，再次申请”，修正后重新提交。若页面提示旧资料已经清理，需要重新补齐资料和图片。

店铺或技师审核通过：从申请页面点击切换到对应身份的按钮。切换成功后进入店铺端或技师端，再确认当前身份。若仍出现权限或切换失败提示，停留在当前页面按提示处理，不要把按钮点击当作切换成功。

本人认证审核通过：查看认证结果即可，无需切换为另一种身份。需要继续店铺申请时，返回店铺申请入口完成剩余步骤。

## 常见提示与检查

资料已变更：另一页面或审核人员可能已经更新申请。保留尚未保存的内容，重新打开申请获取最新状态后再操作。

账户名义不一致：检查片假名、个人／法人申请类型，以及本人认证或法人名称。请以实际开户资料为准，不要根据 TEST 截图填写。

提交或读取失败：检查网络并按页面提示重试。重新进入后先确认是否已存在审核中的申请，避免误以为请求失败就一定没有提交成功。
