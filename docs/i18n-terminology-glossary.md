# NeeDo 多语言翻译用语集

本文档以简体中文为源语言，约束繁体中文、日语、英语、韩语在 NeeDo 前端里的统一译法。所有多语言表、截图复查和新增文案应优先套用这里的术语。

## 翻译原则

- 简体中文是唯一源文案，不直接从日语或英语反推其他语言。
- 品牌词 `NeeDo`、`Afirieito`、`NDP`、`CPS`、`QR`、`Deep Link` 不翻译。
- 英文和韩文不得夹带简体中文；日语不得出现明显简体字或中英韩混排译法。
- UI 按钮和标签优先短词；说明文保持自然完整句，不逐词硬译。
- 后台产品词以专业 SaaS 口吻为准，移动端以用户能立即理解为准。

## 截图复查规则

- 每个主入口至少检查 `简中`、`日本語`、`English`、`한국어` 四种状态；繁中优先通过表格检查和关键页面抽检。
- 英文截图中如出现连续中文、日文截图中出现简体字、韩文截图中出现中日文混排，均视为 P0 翻译问题。
- 按钮、标签、tab、导航优先检查是否溢出；说明文优先检查是否自然、是否半翻译。
- 复查重点页：用户首页、预约/结算、消息、NeeDo、商户端日程、技师端日程、商户后台调度中心、平台后台、Afirieito。
