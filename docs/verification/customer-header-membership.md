# 顶部头像会员徽章

2026-09-07：头像通过 useCustomerSelfProfile 读取的旧客户档案 membershipLevel 与资料页使用的正式平台会员可能不同，因此旧 gold 字段会让正式免费会员仍显示皇冠。

共享个人资料 hook 改为使用平台会员 getMine 返回的 tierCode，覆盖显示用的旧等级；首页、Social、日程等复用该 hook 的头像保持一致。正式 free 不显示付费徽章，gold 仍显示；会员请求失败时保留成功加载的基本资料，将显示用等级置空，不回退旧付费等级，不阻断日程与资料设置。未修改会员权益、账单或数据库记录。

测试覆盖旧 gold / 正式 free、正式 gold、会员不可用保留资料，以及请求并发复用、资料失败重试和过期请求响应。

本地真实登录页面验收：首页顶部头像正常显示 Lv.1，付费徽章节点为空；菜单等相关回归总计 130 项通过，前端构建通过。
