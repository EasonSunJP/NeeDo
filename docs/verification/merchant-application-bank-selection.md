## 本人验证页重构（2026-09-07）

用户设置 `/me/settings/verification` 的原有“实名认证已完成 / 本人一致性已核验 / 信用良好”均为静态展示，不能作为银行账户绑定的 eKYC 证据。用户要求移除整块认证状态卡片及刷新按钮，页面现直接从资料填写进度开始；设置首页的本人验证入口使用中性的“查看状态”。

表单按参考保留姓名/片假名、出生日期/性别、地址、职业输入和确认两步；排除居住形态、联络先、邮件、银行卡、交易目的。采用通用关闭头部、隐藏底部导航和红色悬浮错误。半角片假名及全角邮编数字规范化，日期按真实日历和当前日期校验。确认后返回编辑保留输入，账户切换重置；不将个人信息写入浏览器存储。

银行绑定仍使用持久化认证记录中的加密片假名姓名进行匹配，不修改认证数据、不绕过校验。未找到认证资料时的文案不再声称点击旧验证页面就能完成认证。仓库目前没有在线 eKYC 发起与服务商回调的完整流程，确认页明确资料未提交并禁用认证提交。核验处理方式已询问用户，待选择后接通；本次页面重构不代表认证接入完成。

验证：模型及组件覆盖必填、片假名、邮编、有效日历日期、职业、自定义职业、确认与返回编辑。页面回归防止恢复静态成功文案和状态卡片。浏览器检查了移动端关闭头部、无底部导航、浮动红色错误，并在独立标签页以测试资料完成填写→确认（片假名/邮编规范化、未提交状态）。
