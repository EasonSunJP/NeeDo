# 店铺申请证件项与错误提示

2026-09-07 用户确认移除“法人或代表者证件照片”项目。申请表不再收集该照片；银行步骤不再要求或上传 `representative_identity`；正式提交和运营批准不再把该照片作为必需证据。法人登记资料、个人 eKYC、银行名义匹配、合同接受、RBAC、版本控制和审计继续沿用原规则。历史已上传文件继续按原有授权和保留规则管理，本次不删除文件或数据库记录。

错误信息通过 `SettingsDetailPage → AppTopBar → FloatingHomeHeader.overlay` 渲染于固定页头的下方，位于玻璃面板之外，不挤占表单布局。提示支持关闭、再次校验后重新显示，并使用 `role="alert"`；错误正文按当前语言翻译。

验证覆盖个人及法人无需代表者照片即可进入合同步骤、提交和批准，以及其余证据缺失时仍然拒绝；前端同时验证提示位置、关闭与再次显示，共享页头测试确认提示未被面板裁切。

浏览器现场读取到 `error.identity_application.ekyc_required`：表单字段通过完整性检查，但个人申请绑定银行账户需要有效 eKYC 的已验证片假名。现在将 eKYC、名义不匹配、版本冲突和最终 401 映射为可翻译的具体提示；401 的自动刷新仍沿用统一 httpClient，不绕过认证。资料上传、草稿更新与合同接受每次成功后即保存返回的申请版本，避免后续请求失败导致下次重试使用旧版本。版本冲突不会静默覆盖其他修改。
