# NeeDo 海外投資人路演 BP｜LINE 節奏精緻版設計規格

## 1. 重新設計目標

現有版本的內容、財務數據與披露口徑已完整，但視覺表達過度依賴白底卡片、等寬模組和相似構圖，整套缺乏上市路演應有的節奏、主次與記憶點。

新版要達成：

1. 參考 LINE IPO 路演的資本市場敘事節奏：單頁單結論、大數字主導、深淺頁交替、圖表與生態圖交替。
2. 保留 NeeDo 的生活服務定位：白色、柔和綠、透明感與親和力，不直接採用 LINE 的黑底亮綠視覺。
3. 使用生成式 AI 製作原創抽象視覺資產，提高封面、章節頁和核心產品頁的精緻度。
4. 減少重複卡片與表格，讓市場、產品、商業驗證、財務與投資回報具有不同的視覺語法。
5. 不改動已確認的財務數據、融資條件、100+店鋪使用意向口徑與產品成熟度披露。

## 2. 參考來源的可借鑑部分

LINE IPO BP 的可借鑑特徵：

- 深色舞台承載核心結論與章節轉場。
- 頁面標題短而直接，通常只表達一個投資判斷。
- 以大數字、單一圖表或單一生態圖主導頁面，不平均分配視覺重量。
- 產品、生態、商業模式和財務頁採用不同構圖，整套節奏有明顯變化。
- 高亮綠只用於關鍵數據、增長與結論，不鋪滿所有元素。

新版不得複製 LINE 的角色、圖示、數據、品牌亮綠、背景或頁面素材，只借鑑結構、節奏與資訊層級。

## 3. 選定方向：方案 A

整套採用「柔和白綠內容頁＋深墨綠重點頁＋AI半透明空間視覺」。

頁面比例：

- 約 70%：白色或極淺霧綠內容頁。
- 約 20%：深墨綠重點頁與章節頁。
- 約 10%：低飽和橙色，僅用於激進情境、風險與資金解鎖提示。

深墨綠頁預計使用於：

1. 第2頁｜投資命題。
2. 第10頁｜產品平台總覽。
3. 第16頁｜CPS雙引擎。
4. 第19頁｜商業驗證。
5. 第26頁｜投資條件與回報。
6. 第31頁｜合規與風險控制。
7. 第34頁｜結尾與下一步。

封面保持明亮，但以AI生成的空間主視覺建立第一印象。

## 5. 字體與層級

為確保繁體中文在 PowerPoint 與 PDF 中穩定顯示，正文與標題繼續使用 `Arial Unicode MS`。

- 封面主標題：34–40 pt，粗體。
- 內容頁標題：28–34 pt，粗體。
- 章節頁核心判斷：34–42 pt。
- 英雄數字：48–72 pt。
- 小節標題：18–22 pt。
- 正文：13.5–16 pt。
- 來源與披露：9.5–11 pt。

標題不加裝飾線；用留白、背景色、數字比例和圖像位置形成層級。

## 6. 生成式 AI 視覺資產

AI圖像必須無文字、無品牌標誌、無可辨識第三方角色，並保留足夠留白供繁體中文排版。

預計生成五組原創資產：

### 6.1 封面／結尾主視覺

- 白色空間中漂浮的半透明霧綠絲帶與玻璃節點。
- 絲帶形成可擴張的服務網路與柔和軌道。
- 右側或中央偏右為主要視覺，左側保留標題安全區。

### 6.2 五方協調網路

- 多個不同大小的半透明節點，由柔性曲線連接。
- 中央深綠核心代表 NeeDo，外圍代表店鋪、中介、服務者、客人與場所。
- 不使用文字標籤，標籤由PowerPoint原生文字補充。

### 6.3 AI排班空間

- 立體時間格、透明時間膠囊、可移動的人員節點和路徑。
- 表達衝突檢查、局部重排與內外部供給調配。
- 保持技術感，但避免藍色科技風或賽博霓虹。

### 6.4 透明點單與消費可視化

- 高級服務場景中的透明選項、確認節點、價格層與明細軌跡。
- 不生成真實人物、店鋪名稱、貨幣文字或可讀菜單。
- 表達「先選擇、再確認、全程可見」。

### 6.5 CPS增長環

- 內容節點、達人節點、預約、履約、歸因與結算形成閉環。
- 使用柔和綠、少量橙色和玻璃質感。
- 中央留出空間疊加NeeDo原生圖形與繁體中文標籤。

AI圖像只負責氛圍、空間與視覺隱喻；所有數據、圖表、標籤和披露必須使用PowerPoint原生元素。

## 7. 版式語法

新版避免每頁都使用四張等寬卡片，改用六種主要版式交替：

1. 半版AI主視覺＋大標題。
2. 一個英雄數字＋一個次要證據圖表。
3. 左右不對稱構圖：40/60或35/65。
4. 全寬原生圖表＋側邊投資判斷。
5. 中央生態圖／流程圖＋少量標籤。
6. 深色章節頁＋單一核心結論。

每頁最多保留四個主要容器；除財務附錄外，不使用大面積密集表格。
