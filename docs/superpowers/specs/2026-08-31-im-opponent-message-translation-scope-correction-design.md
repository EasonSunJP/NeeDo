# IM 对方消息自动翻译范围修正设计

## 目标

把“聊天内容自动翻译”收回到用户确认的唯一范围：一对一聊天页中，对方发送的消息气泡正文，以及对方图片/视频消息的说明文字。开关关闭后，界面立即从 Store 中的服务端原文重新渲染。

语言能力显示和好友申请按钮属于用户另外明确要求的修复，继续保留并回归验证。

## 明确不翻译

- 当前账号自己发送的消息。
- 系统消息、撤回残留、判断贴纸、文件名和卡片字段。
- 气泡内引用预览和输入框上方的待发送引用预览。
- 会话列表摘要、置顶摘要、会话内搜索结果。
- 复制结果、转发、重发、撤回恢复和任何持久化 payload。

## 实现边界

- 保留现有服务端 `ConversationParticipant.autoTranslateMessages` 偏好和联系人信息页开关，因为它提供按身份、按会话的正式持久化边界。
- 在会话页按 `message.senderId !== store.currentUserId` 计算气泡正文翻译资格；本人消息始终传入关闭的翻译选项。
- `MessageBubble` 只把该选项用于当前消息的 text/emoji 正文和 image/video caption；引用预览固定读取原文。
- 删除为会话摘要、置顶、搜索和复制翻译新增的调用、预览 provenance 模型及对应测试；保留 `data-no-i18n` 原文保护，避免全局 UI i18n 把用户内容误当界面文案。
- 不修改数据库 schema、后端接口、翻译提供方或消息发送合同。

- 运行聚焦测试、前端全量测试、TypeScript lint、生产构建与差异检查。
