# 用户端首页轮播图设定页紧凑改版设计

## 目标

把运营后台的用户端首页轮播图设定页改成一屏可以理解和操作的发布工作台。页面继续使用正式轮播发布 API、五语言数据、RBAC、审计和历史版本，不新增浏览器状态、mock 或第二套发布模型。

## 页面结构

页面按以下顺序单列排列：

1. 顶部状态标题，只显示草稿、已发布、定时发布的简短状态。
2. 发布结果预览，直接复用用户主页的 `FeatureCarousel` 组件和相同卡片比例。预览优先显示当前草稿；没有草稿时显示当前已发布版本。
3. 五个语言快捷按钮：日本語、English、한국어、繁體中文、简体中文。切换语言同时更新预览、当前内容和替换内容。
4. 当前已发布内容容器：显示所选轮播的缩略图、文字、目标和上次发布时间。缩略图可打开大图。
5. 向下替换箭头：明确表达“上方内容将被下方草稿替换”。
6. 新内容容器：显示同一顺序位置的草稿图片和文字编辑控件，并保留图片上传、目标选择、启用、增删和排序能力。
7. 固定含义的发布操作：保存草稿、立即发布、选择时间后定时发布。一次操作作用于整个五语言草稿，不提供单语言保存或单语言发布按钮。
8. 历史版本与停用/回滚能力保留在页面底部的折叠区域，默认不占用主工作流高度。

## 交互规则

- 预览使用 `FeatureCarousel`；点击任一轮播后选中该项并暂停自动轮播，避免编辑过程中跳走。
- 当前与草稿按轮播顺序位置进行对照，不能因为克隆后 ID 改变而错配。
- 点击当前或草稿缩略图打开同页大图对话框；关闭后焦点回到触发按钮。
- 新建草稿仍从当前已发布版本克隆并填写修改说明，保留现有审计语义。
- 上传默认图片后可作为五语言共同图片；当前语言仍可上传单独图片。
- “复制当前语言到其他语言”是显式五语言同步动作，其他语言随后仍可分别修改。
- 发布前继续执行服务器端五语言完整性、媒体、目标、版本锁和权限校验。
- 上次发布时间使用已发布 Release 的 `activatedAt`，按运营后台当前语言和本地时区格式化；没有发布时间时显示稳定空值。

## 组件边界

- `FeatureCarousel` 继续负责滑动、自动轮播、受控选中和主页视觉。
- 新增一个用户首页专用的紧凑工作区展示组件，负责预览、语言栏、前后对照和大图；它不读取 API，也不持有发布状态机。
- `LocalizedCarouselEditor` 继续负责 API、草稿状态、上传、目标搜索和发布动作，并仅在 `user-home` 场景启用紧凑布局。
- 联盟公告轮播继续使用现有布局，不在本微步骤中改造。

## 视觉约束

- 继续沿用运营后台现有白色面板、`moss` 强调色和设计 token，不另造主题。
- 顶部轮播最大宽度沿用 `FeatureCarousel` 的 `856px`，高度控制在桌面约 `220px`，不再渲染接近整页高度的大图。
- 当前与新内容容器在宽屏两列、窄屏单列；图片保持 15:8 比例且只显示缩略图。
- 唯一显著视觉标记是居中的替换箭头，其余信息保持克制。
- 键盘焦点、对话框语义、减少动态效果和小屏横向溢出必须可用。

## 验收

- 页面顶部真实复用 `FeatureCarousel`，点击轮播会选中并停止自动轮播。
- 1440x900 视口中至少完整看到顶部预览、五语言按钮和当前内容容器，不再被单张图片占满页面。
- 当前容器显示上次发布时间；缩略图能打开大图。
- 新内容容器可编辑、上传、同步语言并执行保存草稿、立即发布、定时发布。
- 保存和发布入口均为五语言整体操作；后端原有原子校验和审计不变。
- 历史版本、停用和回滚仍可用，但默认折叠。
- 联盟公告轮播和用户主页正式轮播读取不回归。
