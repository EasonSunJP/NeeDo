# NeeDo 共享浮动头部四角圆角设计

日期：2026-08-25

## 目标

将 NeeDo 各端复用的浮动玻璃头部从“顶部直角、底部 28px 圆角”统一为四个角均为 28px 圆角。保持现有头部高度、内容、交互、主题、玻璃效果和页面数据流不变。

## 范围

- 更新 `src/components/mobile/FloatingHomeHeader.tsx` 的共享圆角契约，使默认头部和 `floatingHeaderGlassPanelClassName` 均使用四角 28px。
- 共享变更覆盖首页、聊天、通讯录、设置、详情、Social、点餐等复用 `FloatingHomeHeader` 的页面。
- 更新 `src/pages/mobile/BusinessCpsPage.tsx` 中仍显式覆盖为顶部直角的 CPS 浮动头部。
- 更新 `src/styles.css` 中 CPS 固定顶部切换栏的底部单独圆角，使其四角均为 28px。

## 不在范围内

- 不改变全屏铺边的系统层、底部抽屉、弹窗或卡片圆角。
- 不改变 `MobileFullscreenHeader` 的内容结构、标题布局或按钮样式；它只通过共享浮动头部自然获得四角圆角。
- 不修改路由、业务逻辑、API、数据库、i18n 文案或主题 token。
- 不扩张或修改当前工作区内其他未提交业务改动。

## 实现方案

采用共享契约优先的最小实现：

1. 将共享面板类中的 `rounded-b-[28px]` 与 `rounded-t-none` 合并为四角 `rounded-[28px]`。
2. 将 `FloatingHomeHeader` 默认面板的底部单独圆角改为四角 28px，保证未传入共享面板类的调用点也一致。
3. 删除 CPS 两处仍会覆盖顶部圆角的局部规则，统一为四角 28px。

不采用逐页散改，因为容易遗漏共享调用点；不采用全局通配 CSS，因为可能影响非头部容器。

## 测试与验收

按测试先行执行：

1. 先扩展圆角契约测试，断言共享头部和 CPS 局部例外均使用四角 28px，且不再包含顶部直角规则。
2. 运行聚焦测试并确认因现有底部单独圆角而失败。
3. 实施最小样式修改后重新运行聚焦测试。
4. 运行前端 lint、完整测试和 build。
5. 在约 iPhone 14 Pro Max 宽度检查首页、聊天/通讯录头部，确认四角弧度一致，内容位置与滚动行为不变。

## 验收标准

- 截图标注的左右顶部角均显示与底部一致的 28px 圆角。
- 所有共享浮动玻璃头部遵循同一四角圆角契约。
- 头部高度、安全区、间距、玻璃背景、按钮和搜索框不发生非预期变化。
- 测试、lint 与 build 通过，并完成真实浏览器移动端视觉检查。
