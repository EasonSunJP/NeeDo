# NeeDo 宠物操作面板层级设计

## 目标

打开宠物操作面板时，宠物必须始终位于面板前方并完整可见。保持现有视觉样式、操作内容、面板定位和宠物位置，不新增第二套面板组件。

## 层级规则

1. 宠物按钮与动画层的堆叠顺序必须高于操作面板。
2. 面板可以在几何位置上与宠物重叠，但不得盖住宠物的任何可见像素。
3. 宠物仍保持可点击、可拖动；面板未被宠物占据的区域保持正常可操作和滚动。
4. 不移动或缩小宠物，不改变现有面板定位算法、宽度、高度和内部滚动。

## 验收标准

- 桌面和 320–430px 宽手机上，打开面板后宠物均完整显示在面板前方。
- 宠物按钮仍可点击和拖动，面板其余区域仍可操作和滚动。
- 现有面板位置、尺寸与内容不发生变化。
- 拜拜、复活、出现和待机动画修复不受影响。

## 验证

- 增加宠物按钮层级高于操作面板的回归测试。
- 运行宠物组件与资源测试、TypeScript 检查和 formal 构建。
- 使用 iPhone 镜像实际打开面板，确认宠物完整显示在面板前方，宠物和面板均可继续操作。
