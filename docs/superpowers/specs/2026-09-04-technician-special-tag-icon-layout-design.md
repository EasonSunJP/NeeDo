# 技师特殊标签图标与紧凑布局设计

## 1. 目标

在现有技师特殊评价标签组件中替换四项图标，并压缩标签卡片的尺寸与间距，使四项在移动端窄屏容器内稳定保持单行四列，不发生卡片、图标、文字或次数徽章重叠。

## 2. 范围

本次只修改共用特殊评价标签的视觉资产、展示名称和紧凑布局：

- `魅力max` 使用人物与闪光图形。
- `服务max` 使用双手托举爱心图形。
- `情绪max` 使用带爱心的对话气泡图形。
- `元气max` 使用带笑脸的太阳图形。
- 四项继续沿用现有紫、蓝、黄、橙主题色。
- 技师资料中的只读特殊标签和服务后评价中的同类标签继续复用同一套图标目录及卡片样式。

不修改评价记录、次数统计、API、数据库、权限、路由、普通评价标签或其他资料卡区域。

## 3. 图标方案

根据用户提供的四张参考图重绘透明 SVG，不直接使用原始 PNG。SVG 使用 `currentColor` 或对应标签的主题色，让图形保持现有四种标签色调，并避免参考图中的白底、棋盘背景和低分辨率边缘进入产品。

每个 SVG 使用统一 `viewBox`、透明背景和居中视觉边界。图形只表达参考图的主体轮廓，不增加新的装饰语义：

1. 人物头像与三枚闪光。
2. 双手托举一颗爱心。
3. 对话气泡中央一颗爱心。
4. 笑脸太阳与八条光芒。

## 4. 紧凑布局

标签容器继续使用四列网格，但将列间距压缩，并移除由固定最小高度和宽高比共同造成的横向最小尺寸约束。每个标签卡片使用明确的紧凑高度、较小圆角和内边距；图标、标题、`max` 与右上角次数徽章按同一比例缩小。

次数徽章仍位于右上角，但减少水平内边距并收回外溢距离，确保徽章不会覆盖相邻标签。标签文字保持两行结构：短中文名称在上、`max` 在下。四项在约 320px 的内容宽度中必须完整显示，且不允许横向滚动、换行或相互覆盖。

服务后评价选择态只保留现有边框与主题高亮，不改变选择逻辑。

## 5. 验证

- 先增加失败测试，锁定四项图标映射、短展示名称和紧凑布局约束。
- 运行相关 Vitest 测试，确认修改后通过。
- 运行前端构建。
- 启动标准前端运行时，在移动端窄宽度下检查四项单行展示、次数徽章、文字与图标均无重叠，同时检查浏览器控制台没有新增错误。

## 6. 完成标准

- 四项图标与用户提供的图 1 至图 4 一一对应。
- 四项保留紫、蓝、黄、橙主题色。
- 可见名称为 `魅力max`、`服务max`、`情绪max`、`元气max`。
- 四项在窄屏中正好单行放下，无横向溢出或重叠。
- 正式评价次数及现有交互行为不变。
