# NeeDo 移除特殊黑与统一头部圆角设计

日期：2026-08-25

## 目标

完整移除 `special-black` 特殊黑 UI 主题，包括产品入口、运行时类型、专用首页、专用底部导航、专用样式、测试与图标资产。曾保存特殊黑偏好的用户自动迁移到最接近的 `cool-black-gray` 冷酷黑灰主题。其余主题复用的浮动玻璃头部统一使用四个角均为 28px 的圆角。

## 产品行为

- 主题设置页不再显示“特殊黑”。
- `ClientTheme` 不再接受 `special-black`。
- 浏览器中遗留的 `special-black`、`special-dark` 或 `特殊黑` 偏好在读取时规范化为 `cool-black-gray`，避免启动失败或空白页面。
- 其余主题保持现有顺序、名称、配色、交互和数据流。
- 首页与底部导航不再进入特殊黑专用渲染分支，统一使用共享页面结构。
- 其余主题的首页、聊天、通讯录、设置、详情、Social、点餐及 CPS 浮动头部统一为四角 28px。

## 删除范围

- 从 `src/theme/ClientThemeProvider.tsx` 删除特殊黑主题类型、定义和 PWA 色配置，并保留旧值到冷酷黑灰的迁移规则。
- 从设置页、分类图标、信息卡和相关测试中删除特殊黑分支。
- 从 `src/pages/user/HomePage.tsx` 删除特殊黑专用组件、辅助函数和完整页面分支。
- 从 `src/components/mobile/MobileShell.tsx` 删除特殊黑专用底部导航分支。
- 删除不再被引用的 `src/components/mobile/SpecialBlackIcon.tsx`。
- 删除 `src/styles.css` 内所有只服务于特殊黑的规则；对与其他主题合并的选择器仅移除特殊黑选择器，保留其余主题规则。
- 删除 `public/icons/special-black/` 下 50 个已跟踪专用图片资产。
- 更新 README 与主题参数文档，移除特殊黑作为现存主题的说明。
- 删除或改写所有要求特殊黑存在的测试。

## 头部圆角实现

1. 将 `FloatingHomeHeader` 的共享面板类从底部单独 28px 圆角改为四角 28px。
2. 将默认浮动头部面板的底部单独圆角改为四角 28px。
3. 将 CPS 浮动头部与固定顶部切换栏的局部底部圆角覆盖改为四角 28px。
4. 不逐页复制圆角类，不使用可能误伤其他容器的全局通配规则。

## 数据与兼容性

此次不修改 API、数据库或业务数据。唯一状态迁移发生在客户端主题偏好规范化阶段：旧特殊黑字符串读取后返回 `cool-black-gray`，随后由现有 Provider 写回有效主题值。自动跟随系统深浅色的用户不受影响。

## 工作区保护

- 当前 `HomePage.tsx` 已有与正式首页数据来源相关的未提交改动；删除特殊黑分支时保留这些现有改动。
- 不修改当前工作区内与 Auth、IM 正式化、商户计费、模拟数据等其他未提交内容。
- 图标资源是 Git 已跟踪文件，删除后仍可从版本历史恢复。

## 测试策略

按测试先行拆成两个可验证行为：

1. 主题删除与迁移测试：先断言主题列表不包含特殊黑、旧特殊黑偏好解析为冷酷黑灰、源码不再存在特殊黑专用渲染和资产引用；确认测试对现状失败后再实施删除。
2. 共享圆角测试：先断言共享头部、CPS 头部与 CPS 固定切换栏均为四角 28px；确认现状失败后再修改样式。

随后运行：

- 主题、首页、移动壳层、设置、分类图标和浮动头部聚焦测试。
- 前端 TypeScript lint。
- 完整 Vitest。
- 正式生产 build。
- 禁止标记扫描及 `special-black` 全仓残留扫描。

## 浏览器验收

在约 iPhone 14 Pro Max 宽度检查全部六套剩余主题：

- 活力黑白、冷酷黑灰、白绿、黑绿、霓虹粉紫、黑金均可选择并刷新恢复。
- 主题列表不显示特殊黑。
- 人工写入旧 `special-black` 偏好后，刷新自动进入冷酷黑灰。
- 首页、聊天、通讯录的浮动头部四个角均为相同的 28px 弧度。
- 头部安全区、搜索框、头像/区域行、操作按钮和滚动行为不发生位移或遮挡。

## 验收标准

- 产品源码、文档、测试和已跟踪资产中不再保留特殊黑 UI 实现；仅兼容迁移测试/解析规则可出现旧字符串。
- 旧特殊黑用户安全迁移到冷酷黑灰。
- 六套剩余主题均使用共享页面结构并可正常切换。
- 六套剩余主题的共享顶部浮动面板均为四角 28px。
- 聚焦测试、lint、完整测试、build 与真实浏览器视觉检查通过。
