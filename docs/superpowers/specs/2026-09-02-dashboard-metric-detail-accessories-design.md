# 数据概要详情入口布局设计

## 目标

统一“综合数据概要”中运营财务、佣金统计、用户与增长三组指标卡的详情入口：入口位于卡片右上角，并明确区分正式可用详情与尚未开放的 TEST 功能。

## 交互与布局

- 指标标题、公式说明按钮位于卡片头部左侧。
- `查看详细数据` 位于同一头部右侧；仅当后端返回非空 `detailRoute` 且 `dataStatus` 为 `ready` 时渲染为可点击按钮。
- 当 `detailRoute` 为 `null`，或 `dataStatus` 为 `not_connected` / `not_available` 时，右上角渲染不可交互的 `TEST` 角标，不渲染详情按钮，也不触发导航。
- 运营财务、佣金统计、用户与增长使用完全相同的判定规则。
- 数值、上一周期、环比、数据状态和计算公式保持原有逻辑。

## 可访问性与验证

- TEST 使用非按钮元素并带 `aria-disabled="true"`。
- 可用详情按钮保留键盘焦点样式。
- 组件测试验证动作位于卡片头部、无路由指标统一显示 TEST、点击正式入口仍传递原路由和指标。
