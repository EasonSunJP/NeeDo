# 完单数认证章图标设计

## 目标

将简易信息卡“完单数”当前使用的四圆点/旧完成图标替换为参考图中的认证章：荧光绿色实心多齿章体，中央为清晰的白色对勾。图标必须在 24px 移动端尺寸与 32px 放大尺寸下保持轮廓清楚，不使用位图素材。

## 范围

- 只修改共享 `AppIcon` 的 `completed` 图形；该图标当前只被技师简易信息卡的完单数指标使用。
- 保持 `IconName`、`data-app-icon="completed"`、指标顺序、数值、间距、颜色继承和无障碍标签不变。
- 不修改店铺评价图标、服务利用次数图标、卡片高度、数据映射、API 或其他业务逻辑。

## 图形规格

- 继续使用 `0 0 24 24` SVG viewBox。
- 章体采用约 16 个均匀外齿与内凹转折形成的闭合矢量轮廓，填充 `currentColor`，从卡片指标栏继承 NeeDo 荧光绿色。
- 白色对勾位于视觉中心，采用圆头、圆角折线；左下起笔、中心转折、右上收笔，线宽在 24px 下仍可辨认。
- 不添加渐变、图片、文字或额外动画；保持图标在深色卡片背景上的高对比度。

## 验收

- 组件测试确认 `completed` 图标包含独立的认证章轮廓与白色对勾路径，并不再输出旧的环形箭头结构。
- 技师简易信息卡继续显示原完单数值和 `data-app-icon="completed"`。
- 相关卡片测试、TypeScript 构建和 Vite 正式构建通过。
- 在约 440px 宽的浏览器卡片预览中检查 24px 图标：齿形均匀、对勾居中、无裁切和模糊。
