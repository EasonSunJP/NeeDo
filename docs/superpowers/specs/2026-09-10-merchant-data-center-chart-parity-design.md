# 商户端数据中心图表与技师端视觉对齐设计

日期：2026-09-10  
状态：用户已确认

## 1. 目标

将商户端个人中心“数据中心”内的订单趋势图调整为技师端数据中心图表的既有设计语言，并为营业额、订单数两条折线补齐每个时间桶的数据节点。

本次只修改商户端趋势图的前端呈现与交互，不改变正式数据接口、店铺身份范围、统计口径、时间筛选、指标卡或异常信息模块。

## 2. 当前问题与根因

商户端 `ShopAnalyticsTrend` 使用独立的简化 SVG：只有网格和两条路径，未为时间桶渲染节点；图例位于图表上方且不可交互，卡片信息层级也与技师端 `TechnicianDualTrendChart` 不一致。

技师端已经提供经过验收的图表模式：标题和说明、右上角双峰值、虚线网格、双独立刻度、每点圆形节点，以及底部可独立控制的双图例按钮。本次以该模式为仓库内唯一视觉基准。

## 3. 设计方案

商户端订单趋势卡保留“订单趋势”标题，并增加与技师端对应的简短说明“同一期间 · 双独立刻度”。右上角分别显示当前周期的营业额峰值和订单数峰值。

绘图区沿用商户端现有主题变量：

- 营业额使用 `--client-primary` 实线。
- 订单数使用 `--client-accent` 虚线。
- 两个序列分别按各自峰值计算纵向坐标，保持现有独立刻度语义。
- 每个时间桶都为两个序列渲染圆形节点；节点以页面背景填充、对应序列颜色描边，尺寸与技师端保持同一视觉等级。
- 横轴标签与节点使用同一坐标源，避免错位。

图表下方使用两列图例按钮。按钮显示线段色样、序列名称，并通过 `aria-pressed` 表示当前可见状态；点击后只隐藏或恢复对应序列，不影响另一个序列，也不重新请求数据。

## 4. 状态与边界

- 无数据时继续显示现有正式空状态，不绘制虚假节点或峰值。
- 零值数据仍绘制在基线上，并显示零值峰值。
- 今日单桶数据的节点位于绘图区中部，不能产生无效坐标。
- 近 30 天等较多时间桶继续限制可见横轴标签数量，但所有正式时间桶都必须保留折线节点。
- 明暗主题全部通过现有 `--client-*` 变量呈现，不新增硬编码主题分支。
- 不抽取跨端共享组件，避免扩大本次微步骤的回归范围；技师端实现保持不变。

2. 增加失败测试，证明底部两个图例按钮初始为可见，可分别隐藏和恢复对应曲线与节点。
3. 实现最小前端改动后运行聚焦测试，并确认现有正式 API 加载、期间切换、失败重试和未知指标测试不回归。
