# 商户端工作台纯色主题背景设计

## 目标

商户端首页“店铺工作台”头部不再使用店铺或图库图片作为背景，改为完全由现有客户端 UI 主题色生成的背景，同时保持标题、店铺信息、四项经营指标和现有布局不变。

## 方案

- 删除 `MerchantPortalPage` 工作台头部内的背景 `<img>`。
- 继续使用现有 `client-feature-panel` 作为主题感知的渐变底色。
- 继续使用现有 `client-feature-aura` 提供同主题下的轻量色彩层次。
- 不新增硬编码商户背景色，不新增图片替代资源，也不修改其他使用 `client-feature-panel` 的页面。

此方案会自动适配白绿、黑绿、黑金、活力黑白、冷酷黑灰和霓虹粉紫主题，颜色来源仍由 `src/styles.css` 中的 `--client-*` 主题体系控制。

## 验收

- 工作台头部源码不再渲染背景图片。
- 工作台仍保留 `client-feature-panel` 和 `client-feature-aura`。
- 标题、店铺名称与地区、今日预约、在线员工、今日流水和利用率保持不变。
- 针对该结构添加一个最小回归测试，并运行目标测试及前端构建。
- 浏览器验收时确认目标商户首页无背景图、文字对比度正常且没有新增控制台错误或横向溢出。

## 非目标

- 不调整工作台卡片尺寸、圆角、间距或文案。
- 不修改经营数据来源和计算逻辑。
- 不更改全局主题色，也不重绘其他商户端或技师端卡片。
