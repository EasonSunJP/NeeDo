# Themed Information Card Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every shared simple information card consume the active NeeDo UI theme and render the completed-order seal with a true transparent check cutout.

**Architecture:** Keep theme ownership in the existing `--client-*` CSS variables and replace fixed card colors at the shared component boundary. Implement the cutout inside the reusable completed icon with a per-instance SVG mask generated by React `useId()`, so callers continue using `AppIcon name="completed"` without new props.

**Tech Stack:** React 19, TypeScript, Tailwind arbitrary values, CSS `color-mix()`, SVG masks, Vitest, Vite.

## Global Constraints

- Card background, border, text, muted copy, accents, tags, separators, actions, and arrow must derive from existing `--client-*` theme tokens.
- Do not introduce theme-name branches or new card color props.
- The completed seal uses `currentColor`; its center check is transparent mask subtraction, not a fixed white/light stroke.
- Each completed icon instance has a unique mask ID produced by React `useId()`.
- Preserve compact height, the three formal completed-order scopes, metric order, i18n copy, and compact number formatting.
- Transparent black on real-image duration/price overlays is allowed for photo legibility; their accent color must use `--client-primary`.
- No API, Prisma, OpenAPI, route, mock, schema, push, or deployment changes.

- [ ] **Step 3: Implement the per-instance mask component**

Import `useId` from React. Add a component before `iconPath`:

```tsx
const COMPLETED_SEAL_PATH = "M12 2 13.63 3.81 15.83 2.76 16.64 5.06 19.07 4.93 18.94 7.36 21.24 8.17 20.19 10.37 22 12 20.19 13.63 21.24 15.83 18.94 16.64 19.07 19.07 16.64 18.94 15.83 21.24 13.63 20.19 12 22 10.37 20.19 8.17 21.24 7.36 18.94 4.93 19.07 5.06 16.64 2.76 15.83 3.81 13.63 2 12 3.81 10.37 2.76 8.17 5.06 7.36 4.93 4.93 7.36 5.06 8.17 2.76 10.37 3.81Z";

function CompletedSealIconPath() {
  const maskId = `completed-seal-${useId().replaceAll(":", "")}`;
  return (
    <>
      <defs>
        <mask height="24" id={maskId} maskUnits="userSpaceOnUse" width="24" x="0" y="0">
          <path d={COMPLETED_SEAL_PATH} fill="white" />
          <path
            d="m7.1 12.1 3.3 3.3 6.8-6.9"
            data-icon-part="completed-check-cutout"
            fill="none"
            stroke="black"
            strokeLinecap="round"
            strokeLinejoin="round"
            strokeWidth="2.4"
          />
        </mask>
      </defs>
      <path
        d={COMPLETED_SEAL_PATH}
        data-icon-part="completed-seal"
        fill="currentColor"
        mask={`url(#${maskId})`}
      />
    </>
  );
}
```

Define `COMPLETED_SEAL_PATH` once with the currently approved 16-tooth path. In `case "completed"`, return `<CompletedSealIconPath />`. Do not change any caller or `IconName`.
