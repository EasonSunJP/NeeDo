# 财务人工结清微步骤

## 目标

把商户财务页现有的固定支付示例改为正式可操作的人工结清流程。NeeDo 只记录财务人员在外部完成的支付，不发起自动转账。

## 范围

1. 工资单正式响应补充员工公开 `NeeDoID`，财务页不以内部用户 ID 识别员工。
2. 从员工详细信息卡进入财务页时，按 `employee=<NeeDoID>` 定位对应工资单。
3. 财务人员可以选择工资单并填写本次支付金额、方式、实际支付日、外部凭证号和备注。
4. 后端继续使用既有 shop-scope、RBAC、Zod、审计和事务化支付记录接口；本微步骤不增加自动转账。
5. 支持部分支付；每次登记后刷新已支付、未支付、状态和支付记录。

## 验收

- 不再出现固定日期、固定流水号或点击即默认全额转账。
- 不能提交零金额、负金额或超过未支付金额的记录。
- 公开 `NeeDoID` 能从 API 到页面完整传递并用于员工定位。
- 支付记录可见，明确显示“仅登记外部支付结果”。
- 前后端相关测试、lint、build 通过，并在本地正式登录态完成浏览器验收。
