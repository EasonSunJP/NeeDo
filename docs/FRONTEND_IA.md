# NeeDo Frontend Information Architecture

## User App

用户端全局提供中文、日本語、English 三语切换，客户端语言与白天 / 黑夜主题集中在「我的」页面管理。用户端、商户端、技师端共享白天 / 黑夜移动主题，白天参考清爽医疗 App 风格，黑夜参考高级酒店 / 旅行 App 风格。

| Route | Page | Purpose |
| --- | --- | --- |
| `/` | 首页 | 定位、搜索、消息/购物车/客服、分类宫格、即时上门、推荐技师、运营位、热门服务、热门店铺、底部导航 |
| `/categories` | 服务分类 | 家庭保洁、上门维修、上门按摩、衣物洗护、搬家拉货、家电清洗、上门安装、上门美业、保姆月嫂、康养护理、深度保洁、擦玻璃、收纳整理、家居养护、上门回收、餐饮预约 |
| `/search` | 搜索页 | 搜索服务、技师、店铺、区域、标签；支持价格、评分、时间、上门、即刻达、时长、女性可选、语言、当日预约、优惠券筛选 |
| `/services` | 服务列表 | 上门服务列表、排序、筛选、服务区域、最快上门、技师数量、销量与评分 |
| `/services/:id` | 服务详情 | 介绍、套餐、价格、时长、技师、评价、流程、须知、推荐、预约、收藏、客服 |
| `/stores` | 店铺列表 | Tabelog 风格门店浏览，区域、评分、评论、人均、标签、营业状态、预约时间 |
| `/stores/:id` | 店铺详情 | 地址、地图入口、营业时间、价格区间、图片、项目/菜单、预约时间、员工、评价、优惠 |
| `/checkout/:serviceId` | 下单/预约流程 | 上门服务与到店预约共用流程：套餐、时间、地址/门店、技师、备注、确认、支付 |
| `/orders` | 我的订单 | 待付款、待服务、进行中、已完成、已取消、改期、客服、评价 |
| `/me` | 用户中心 | 个人资料、订单、收藏、优惠券、地址、评价、钱包、会员、语言、主题、客服、账号安全、角色入口 |
| `/support` | 客服中心 | 订单咨询、退款、改期、商家入驻、投诉风控 |
| `/merchant` | 商户端工作台 | 门店今日预约、待确认、营收、评价、排班、营销入口 |
| `/technician` | 技师端工作台 | 接单状态、下一单、今日工单、移动时间、排班、异常上报 |

## Admin SaaS

后台顶部工具栏提供中文、日本語、English 三语切换，所有核心模块共享同一语言状态。运营控制台同时提供黑夜 / 白天两套主题，视觉风格参考高密度 SaaS / 金融仪表盘。

| Route | Module | Scope |
| --- | --- | --- |
| `/admin` | Dashboard | 今日营收、订单、新用户、活跃、复购、取消、退款、客单价、利用率、库存预警、工单、审核 |
| `/admin/analytics` | Analytics | 营收、订单、用户、复购、留存、高峰、来源、渠道、城市、商家、技师、类目、退款、评价 |
| `/admin/data` | Data Center | 订单、客户、员工/技师、门店、商家、库存、评价、结算统一表格 |
| `/admin/orders` | Orders | 全状态订单、详情、日志、客服记录、确认、改期、派单、改价、取消、退款、收款、打印 |
| `/admin/dispatch` | Dispatch | 日/周/月排班、工单调度、冲突提醒、空闲查看、移动预估、区域派单 |
| `/admin/field-jobs` | Field Jobs | 待派工、已派工、服务中、已完成、异常工单、拍照、完工、异常上报 |
| `/admin/crm` | CRM | 客户列表、会员、标签、LTV、订单、最近消费、下次预约、活跃评分、流失预警 |
| `/admin/marketing` | Marketing | 优惠券、活动、新人券、回流券、限时券、满减券、裂变、渠道归因、GMV、ROI |
| `/admin/finance` | Finance | 营收、待结算、退款、手续费、商家/技师分账、退款审核、结算导出、发票 |
| `/admin/reviews` | Reviews | 好中差评、未回复、敏感评价、回复、标记处理、风控、差评预警 |
| `/admin/merchants` | Merchants | 多门店、资料、营业时间、服务区域、图片、项目菜单、标签、状态、入驻审核 |
| `/admin/inventory` | Inventory | 库存列表、预警、采购、调拨、入库、出库、耗材规则、变动记录 |
| `/admin/floorplan` | Floorplan | 包间、床位、桌位、工位、区域编辑、状态、利用率、消费记录 |
| `/admin/roles` | Roles | 平台管理员、运营、财务、客服、商家管理员、店长、技师/员工权限矩阵 |
